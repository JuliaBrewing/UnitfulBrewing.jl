API reference

UnitfulBrewing — Module
UnitfulBrewing

Module extending Unitful.jl with beer brewing units, and with equivalences, via UnitfulEquivalences.jl, between quantities that are used interchangeably in brewing.

The units are available through Unitful's u"..." string macro once the package is loaded, e.g. u"°P", u"SRM" or u"vols".

Equivalences

UnitfulBrewing.SugarGravity — Type
SugarGravity()

Equivalence to convert between Sugar Contents and Specific Gravity quantities.

Convert between degrees Plato and specific gravity according to the equation

Plato = 259 * (1 - 1/sg),

Examples

julia> uconvert(u"°P", 1.040u"sg", SugarGravity())
9.961538461538483 °P
julia> uconvert(u"sg", 15u"°P", SugarGravity())
1.0614754098360655 sg
julia> uconvert(u"gu", 12u"°P", SugarGravity())
48.58299595141693 gu
julia> uconvert(u"°P", 40u"gu", SugarGravity())
9.961538461538483 °P

UnitfulBrewing.SugarGravityQuad — Type
SugarGravityQuad()

Equivalence to convert between Sugar Contents and Specific Gravity quantities.

Convert between degrees Plato and gravity units according to the quadratic equation

Plato = 0.25802gu - 0.00020535gu^2,

which is equivalent to the formula for specific gravity

Plato = 668.72 * sg - 463.37 - 205.35 * sg^2,

with

gu = 1000 ( sg - 1.000 ).

Examples

julia> uconvert(u"°P", 1.040u"sg", SugarGravityQuad())
9.992240000000002 °P
julia> uconvert(u"sg", 15u"°P", SugarGravityQuad())
1.0611068377146748 sg
julia> uconvert(u"gu", 12u"°P", SugarGravityQuad())
48.370088784473296 gu
julia> uconvert(u"°P", 40u"gu", SugarGravityQuad())
9.992240000000002 °P

UnitfulBrewing.DensityConcentration — Type
DensityConcentration()

Equivalence to convert between Density and Concentration for water-based solutions, with relatively small quantities of solutes, as in water treatment, so that 1 mg/L is equivalent to 1 ppm (parts per million).

Examples

julia> uconvert(u"mg/l", 10u"ppm", DensityConcentration())
10 mg L⁻¹
julia> uconvert(u"ppm", 1u"g/l", DensityConcentration())
1000.0 ppm

UnitfulBrewing.CarbonationDensity — Type
CarbonationDensity()

Equivalence to convert between carbonation, in volumes of CO₂ per volume of beer (vols), and the density of dissolved CO₂, using the density of CO₂ at 0 °C and 1 atm, so that 1 vols is equivalent to 1.977 g/L.

Examples

julia> uconvert(u"g/l", 2.5u"vols", CarbonationDensity())
4.9425 g L⁻¹
julia> uconvert(u"vols", 5u"g/l", CarbonationDensity())
2.529084471421345 vols

Internals

These functions are not exported. They implement the quadratic relation used by SugarGravityQuad.

UnitfulBrewing.gu_to_plato — Function
gu_to_plato(gu::Number)

Convert a value in gravity units to degrees Plato according to the quadratic formula

Plato = 0.25802 gu - 0.00020535 gu^2,

which is equivalent to the formula for specific gravity

Plato = 668.72 sg - 463.37 - 205.35 sg^2,

with gu = 1000 (sg - 1).

This is the relation used by SugarGravityQuad.

UnitfulBrewing.plato_to_gu — Function
plato_to_gu(p::Number)

Convert a value in degrees Plato to gravity units by inverting the quadratic formula of gu_to_plato, taking the root in the range of interest:

gu = e - sqrt(e^2 - g p),

where

e = 0.25802 / (2 × 0.00020535) = 628.2444606768931,
g = 1 / 0.00020535 = 4869.734599464329.

For p > e^2 / g ≈ 81.05, far beyond any wort, the quadratic has no real inverse, and e is returned just for definiteness, although the conversion is meaningless there.

This is the relation used by SugarGravityQuad.
